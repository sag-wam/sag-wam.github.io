# Speculative Action Generation for World Action Models

This repository contains the source code for the **SAG project website**.

**[Project Page](https://sag-wam.github.io/) · [Algorithm Repository](https://github.com/Griseo-Kaslana/SAG)**

SAG is a plug-and-play inference acceleration framework for World Action Models,
without additional training or auxiliary models. The project page presents robot
demonstrations, animated explanations of SAG-Residual and SAG-Coupling, and
experimental results. The algorithm implementation is maintained in the separate
repository linked above.
